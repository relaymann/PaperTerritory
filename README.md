# PaperTerritory

Original Android real-time territory game based on the territory/trail gameplay requested from the supplied reference footage. No world map and no copied proprietary branding/assets.

Included: native Android client, server-authoritative WebSocket gameplay, touch steering, territory claiming, exposed-trail elimination, public matchmaking, five-character private rooms, live leaderboard, respawn flow, Render Blueprint, and GitHub Actions APK builds.

The reference YouTube URL was not directly fetchable by the build environment, so implementation follows the gameplay requirements supplied in chat rather than claiming frame-for-frame reproduction of unavailable footage.
